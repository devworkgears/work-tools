# 運転範囲 可視化ツール

選定図(流量×全揚程の対数-対数平面に各モデルの運転範囲を多角形で示す図)をインタラクティブに探索・可視化するツール。要件・設計は [curve-chart-requirements.md](./curve-chart-requirements.md)、DB化・選定システムへの拡張計画は [docs/ROADMAP.md](./docs/ROADMAP.md) を参照。

## 使い方

```bash
npm run serve   # = python3 -m http.server 8000
# → http://localhost:8000/index.html を開く
```

1. 「サンプル表示」でデモデータを表示、または「テンプレDL」でExcel雛形を取得
2. 雛形の `models` / `curves` / `config` シートに自社データを記入
3. 「Excelを読み込む」またはチャート領域へドラッグ&ドロップ

## 機能(初版)

| 分類 | 内容 |
|---|---|
| データ入力 | .xlsx読み込み(D&D対応) / テンプレートDL(説明シート付き) / バリデーション(エラー箇所を行番号つきで提示) |
| 下限導出 | `explicit` / `neighbor` / `clip` / `ratio` / `trim` の5ルール(要件書§3.3) |
| 描画 | 対数-対数軸、半透明ポリゴン、シリーズ色分け(フィルタに凡例スウォッチ)、重心ラベル+重なり回避、グリッド |
| 表示モード | 個別モデル / グループ外包(合併境界・凸包をトグル比較可。集約軸は任意属性を選択可) |
| 探索 | 属性チェックボックスフィルタ(AND複合・任意列自動反映)、ホバー詳細、クリック選択ハイライト、カーソル位置のQ-H読み取り |
| 軸 | 自動レンジ + 手動上書き + configシートで固定範囲指定(`axis_qmin`等) |
| 出力 | SVG / PNG(3倍解像度)ダウンロード |
| 実図デジタイザ | 既存選定図のスキャン画像を背景に重ね、2点較正→クリックで点列採取→curvesシート形式でExcel出力 |

## 実図デジタイザの使い方(実データ整備の支援機能)

1. 「実図画像を開く」で既存選定図のスキャン(png/jpg)を読み込む(軸範囲全体に仮表示される)
2. 較正: 実図上で座標が読める2点(例: 軸交点や目盛の交わり)についてQ・H値を入力し、「点N をクリック指定」→チャート上のその位置をクリック。2点指定すると画像が軸に整合する
3. 「採取モードON」にし、モデル名・カーブ種別(upper/lower)を選んで実図のカーブ上をクリックしていく
4. 「採取点をExcel出力」→ curvesシート形式でダウンロード。テンプレのmodelsシートに属性を補記すればそのまま読み込める

## 開発

```bash
npm ci       # devDependencies(テスト用jsdom等)の取得
npm test     # ドメイン層の単体テスト + jsdomによるUI操作テスト + 配布物テスト
npm run build && npm test   # 配布物テスト(dist)も含めて実行
```

UI層のテストはjsdom上でindex.html+main.jsを実際に起動して操作を再現するため、**ブラウザでの手動確認なしに回帰を検知できる**。push時にGitHub Actionsで build + 全テストが自動実行される(`.github/workflows/test.yml`)。

```
src/
├── domain/      # 純粋関数(移植対象): parser / geometry / envelope / query
├── ui/          # main(状態管理) / chart(SVG描画) / exporter
├── vendor/      # polygon-clipping(union外包用、esbuildで単一ファイル化)
└── sample-data.js  # サンプル=テンプレートの中身
tests/           # ドメイン層のテスト
```

## 性能(NFR-1)

合成データによる計測(Node v22 + jsdom、中央値。実ブラウザのレイアウト・ペイントは含まないJS処理時間):

| モデル数 | 頂点数 | parse | lower導出 | 再描画(個別) | union外包+描画 |
|---|---|---|---|---|---|
| 100 | 2,870 | 1.1ms | 0.3ms | 11ms | 6ms |
| 300 | 8,740 | 1.9ms | 0.5ms | 24ms | 13ms |
| 1,000 | 29,350 | 6.7ms | 0.9ms | 64ms | 37ms |

NFR-1の目標(100モデル・3,000頂点で再描画<100ms)は大幅に余裕あり。ラベル重なり回避込みで50モデル同時表示まで全ラベルが判読可能なことを確認済み。それ以上はフィルタか外包モードで絞る運用を推奨。

## 配布

### 配布物の作成

```bash
npm run build   # → dist/curve-chart-vX.Y.Z.html(自己完結・約1MB)
```

生成される単一HTMLは**ダブルクリックで開くだけで動作**する(インストール・サーバー・ネット接続すべて不要)。D3/SheetJSも埋め込み済みで外部通信は一切行わず、読み込んだExcelデータがPC外に出ることはない(NFR-2/NFR-3)。版数とビルド日はサイドバー下部に表示される。

### リリース手順

1. `npm pkg set version=X.Y.Z` でバージョンを上げる
2. `npm run build`
3. `git commit` → `gh release create vX.Y.Z dist/curve-chart-vX.Y.Z.html` で版管理(リポジトリはprivateのままでよい)
4. 生成したHTMLファイルを社内ファイルサーバー・Teams等で配布

### 配布時の注意

- ツール本体に実データは含まれない(サンプルデータは架空)。実データ入りExcelの管理・配布可否はデータ側で判断する
- 対応ブラウザ: Chrome / Edge 最新版
- 不具合報告はサイドバー下部の版数表記+読み込んだExcelを添えてもらう
