# 運転範囲 可視化ツール

選定図(流量×全揚程の対数-対数平面に各モデルの運転範囲を多角形で示す図)をインタラクティブに探索・可視化するツール。要件・設計は [curve-chart-requirements.md](./curve-chart-requirements.md) を参照。

## 使い方

```bash
npm run serve   # = python3 -m http.server 8000
# → http://localhost:8000/index.html を開く
```

1. 「サンプル表示」でデモデータを表示、または「テンプレDL」でExcel雛形を取得
2. 雛形の `models` / `curves` / `config` シートに自社データを記入
3. 「Excelを読み込む」またはチャート領域へドラッグ&ドロップ

## 機能(初版)

| 分類 | 内容 |
|---|---|
| データ入力 | .xlsx読み込み / テンプレートDL / バリデーション(エラー箇所を行番号つきで提示) |
| 下限導出 | `explicit` / `neighbor` / `clip` / `ratio` / `trim` の5ルール(要件書§3.3) |
| 描画 | 対数-対数軸、半透明ポリゴン、シリーズ色分け、重心ラベル、グリッド |
| 表示モード | 個別モデル / グループ外包(対数空間の凸包。集約軸は任意属性を選択可) |
| 探索 | 属性チェックボックスフィルタ(AND複合・任意列自動反映)、ホバー詳細、クリック選択ハイライト |
| 軸 | 自動レンジ + 手動上書き |
| 出力 | SVG / PNG(3倍解像度)ダウンロード |

## 開発

```bash
npm test   # ドメイン層の単体テスト + 統合テスト(node --test、追加依存なし)
```

```
src/
├── domain/      # 純粋関数(移植対象): parser / geometry / query
├── ui/          # main(状態管理) / chart(SVG描画) / exporter
└── sample-data.js  # サンプル=テンプレートの中身
tests/           # ドメイン層のテスト
```
